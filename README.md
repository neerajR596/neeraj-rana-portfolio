# Neeraj Rana Portfolio

Personal portfolio built with React and Vite.

## Local development

```sh
npm ci
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Netlify builds with `npm run build` and publishes `dist`.
Profile, skills, education, and projects are maintained in `src/data.js`.
The contact form opens the visitor's email application with a prefilled message.
